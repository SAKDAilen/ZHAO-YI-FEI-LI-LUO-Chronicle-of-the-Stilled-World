# 招亦废丽罗 · 律令之楔

**ZHAO YI FEI LI LUO — Chronicle of the Stilled World**

**v5.0 · HTML 版**（纯 HTML + CSS + JavaScript · Canvas 2D · 零依赖）  
东方废土 × 生物机械美学的俯视 2.5D 开放世界动作游戏：程序化生成的 8192×8192 米世界、十种地貌、昼夜/天气/能量潮汐、三套兵刃与格挡弹反、精英词缀敌人、四 NPC 对话树与任务、五楔之坛、装备成长、成就/图鉴/地图/篝火面板与本地存档。**无需安装、无需构建、无需联网**，双击即可在浏览器游玩。

---

## 一、如何运行

| 方式        | 操作                                                                        |
| --------- | ------------------------------------------------------------------------- |
| 手动打开      | 双击 **`index.html`**；或把它拖进 Chrome / Edge / Firefox                         |
| 本地服务器（可选） | 在 `2.5DHTML` 目录执行 `python -m http.server 8000`，访问 `http://localhost:8000` |

**环境要求**：任意支持 Canvas 2D 与 ES6 的现代浏览器（Chrome / Edge / Firefox 近三年版本）。不需要 Node.js、不需要 Unity、不需要联网；所有美术、音效、数据均由代码生成或内嵌。

> 存档写入浏览器 `localStorage`（键名 `zhaoyi_web_save_v1`），换浏览器或清理站点数据会丢失存档；标题界面可「继续旅程」。

## 三、玩法细节

### 1. 探索

- **程序化世界**：8192×8192 米，按 128 米区块流式生成并缓存；高度场、区域、植被、矿脉全部由种子噪声决定。
- **十种地貌**：楔之峰、泪湖、回声山、熔炉峡谷、青铜林、沉沙外域、冻原、烬野、裂谷、荒原，各有独立配色与植被。
- **地标**：五座楔坛（激活后可传送）、四座篝火、八块碑文、十六处晶簇、五只遗物匣（含三只稀有匣）、四眼灵泉、十二处矿脉、十二丛苔草、峰顶祭坛。
- **昼夜与天气**：24 分钟一昼夜；晴朗 / 多云 / 薄雾 / 细雨 / 沙尘 / 晶尘雨六种天气，影响能见度与色调；能量潮汐随时间起伏。
- **环境生物**：萤火虫、飞鸟、尘埃、薄雾、流星（按地貌与时段出现）。

### 2. 战斗

- **三套兵刃**：青铜律刃（均衡）、霜晶双刃（快速、附霜蚀减速）、熔痕巨剑（高伤、附灼烧持续伤害）。
- **攻防转换**：三段连击、重击、格挡、弹反、翻滚、完美闪避、背刺（1.55×）、暴击（8%）。
- **律令模式**：满能量后 10 秒伤害 ×1.5，配合连击可爆发。
- **敌人**：构造机偶、飞翼幽魂、熔岩兽；精英带「迅捷 / 重甲 / 嗜血」词缀，拥有蓄力预警圈、受击硬直、霜蚀/灼烧状态与击退。
- **伤害数字**：普通、暴击、背刺、元素伤害分色显示。

### 3. 成长

- **等级与经验**：击杀、任务、碑文、宝箱、世界事件获得经验；升级提升生命/耐力上限并解锁兵刃。
- **强化**：篝火处消耗晶尘与楔铁强化当前兵刃（最高 +5），提升伤害、缩短挥砍时间。
- **护符**：五枚（守夜人之眼、钟漏残片、熔火之心、回声铃、拾荒者徽），提供耐力、律令、伤害、移速、掉落等加成。
- **材料与合成**：晶尘、楔铁、兽骨、火髓、苔草；可合成药剂、强健药剂、磨刀石。
- **成就与图鉴**：12 项成就、三型敌人击杀图鉴、战斗统计。

### 4. 交互与叙事

- **四 NPC**：钟漏（引导）、回声（支线）、守夜人（守夜）、行商（交易），共四棵对话树、四十余节点，支持分支条件与任务推进。
- **任务链**：序章、回声、守夜、五坛四条任务线，追踪面板实时显示阶段。
- **碑文与碑铭**：八块碑文提供世界观文本与经验。
- **篝火**：休息（回满并推进时间）、强化兵刃、合成道具。
- **楔坛**：激活后永久获得属性加成，并解锁地图传送点。

### 5. 界面

- 左上区域名 / 时间 / 天气 / 任务追踪；右上等级 / 经验 / 材料。
- 底部生命、耐力、律令条与当前兵刃、护符、连击数。
- 锁定目标血条、词缀、状态标记；小地图实时绘制地形与兴趣点。
- 装备 / 地图 / 手记 / 篝火四套全屏面板，支持键鼠操作。

### 6. 存档

- 自动与手动保存：位置、时间、天气、生命/耐力、等级/经验、兵刃与强化、护符、材料、任务、楔坛、成就、图鉴、战斗统计。
- 读档恢复到上次位置；死亡后在最近篝火重生。

## 五、技术说明

- **零依赖**：不使用 three.js、React、构建工具或外部 CDN；`file://` 直接打开即可运行。
- **逐块流式地形**：每块 128 米生成 512×512 纹理（高度着色 + 区域配色 + 细节笔触），只保留相机附近区块；植被按区块种子确定，重访一致。
- **2.5D 投影**：世界坐标 `(x, z)` 经 `zoom`、`YS=0.82` 压缩投影到屏幕，实体按深度排序绘制。
- **音频**：WebAudio 实时合成风声、雨声、篝火、剑击、弹反、升级等音效，无外部音频文件。
- **存档**：`localStorage` JSON，字段带版本号，便于后续迁移。

## 六、自检与调试参数

在地址后追加查询参数（可组合）：

| 参数            | 用途                                                                          |
| ------------- | --------------------------------------------------------------------------- |
| `?debug=1`    | 左上角显示坐标、区块、实体数、帧率、渲染像素等调试信息                                                 |
| `?play=1`     | 跳过标题，1.4 秒后自动开始新游戏                                                          |
| `?selftest=1` | 运行页内自检（移动 / 攻击 / 击杀 / 面板 / 对话 / 存档），结果显示在左上角并将标题设为 `SELFTEST-PASS` / `FAIL` |
| `?clean=1`    | 隐藏全部 DOM 覆盖层，便于截图检查地形渲染                                                     |
| `?forcehud=1` | 强制显示 HUD（部分无头浏览器会冻结透明度过渡）                                                   |

示例：`2.5DHTML/index.html?play=1&debug=1`

## 七、已知限制

- 俯视 2.5D 视角，非 3D 自由镜头；角色与敌人为程序化矢量绘制。
- 移动端触屏未适配（建议桌面端键鼠游玩）。
- 首次进入需生成 3×3 区块，低端设备可能有约 1 秒加载。
- 存档仅保存在当前浏览器；清理站点数据会丢失。
